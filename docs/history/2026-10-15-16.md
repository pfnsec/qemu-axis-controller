## Second off-board hardening pass — control failures and ARM32 (2026-10-16 UTC)

This pass targets different failure classes rather than only increasing seeds.
The unchanged driver actually returned success from QUERY_CAPS after the
simulator disconnected during its version read. The old close path then spent
30 seconds trying to establish idle. That failing reproducer is retained at
`artifacts/hardening2-caps-reproducer/`; it is not counted as a passing test.

Changes:

- Identity/capability checks now reject failed or inconsistent control reads.
  SUBMIT checks the device after configuration and after START; RESET checks
  after its write. Failed identity/idle reads latch offline immediately rather
  than spending the close budget retrying a dead bridge. An accepted START with
  a lost reply remains uncertain execution: buffers are not freed or retried.
- IRQ handling validates reserved bits, terminal state, error-code range and
  agreement, and expected byte counts. Inconsistent telemetry disables the
  Linux IRQ without waiting in the handler, wakes waiters and latches offline.
  Recoverable DMA errors still permit partial counters and normal recovery.
  A later independently verified idle permits reclamation; otherwise the
  existing quarantine contract remains mandatory.
- The real-RTL socket simulator supports precisely targeted, post-acceptance
  MMIO disconnections and one-shot read-payload corruption. Arguments now use
  strict, range-checked parsing before any socket is created.
- `CONFIG_COMPAT` and a freestanding ARM EABI fixture provide actual 32-bit
  userspace execution, not only structure-layout compilation. It checks ioctl
  pointers, high job-ID bits, mmap2 offsets, image/guard correctness, RESET,
  executable-map rejection and final-VMA ownership/reclamation on one/four CPUs.
  Host clang/lld 22.1.8 build it without another guest libc or toolchain download.
- M4/stress evidence readers bound JSON records and binary comparisons and
  validate types, geometry, allocation extents and counters before constructing
  reference images. Host-derived filenames cannot be overwritten by guest JSON.
  New negative tests include oversized sparse files and bool-as-integer fields.

The tests themselves were corrected during development: one-page coherent
allocations bypass this kernel's global CMA, so accounting fixtures now use
two 8-KiB allocations; the compat fixture reinitializes WAIT's input timeout
after a previous result copyout. These were test assumptions, not driver bugs.
